# homebrew-tap

Personal Homebrew tap for [panic-kit](https://panic-kit.com) apps.

```sh
brew tap ivshestakov/tap
brew install --cask vaqlo
```

| Cask    | App                                                    |
|---------|--------------------------------------------------------|
| `vaqlo` | [Vaqlo](https://panic-kit.com/vaqlo/) — local meeting recorder |
